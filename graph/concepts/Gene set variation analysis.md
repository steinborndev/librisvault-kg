# Gene set variation analysis

GSVA turns a gene-by-sample expression matrix into a pathway-by-sample matrix of enrichment scores without needing predefined sample groups, so pathway activity can be compared between samples or subgroups.

## Connections

- Showed immune and signalling pathways (B cell receptor, Toll-like receptor, complement, WNT, axon guidance) with lower activity in one of two Alzheimer brain subtypes. Study: [[CDK5R1-related subtypes and immune infiltrates in Alzheimer disease]]

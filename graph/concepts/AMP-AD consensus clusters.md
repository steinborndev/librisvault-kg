# AMP-AD consensus clusters

A harmonized set of 30 aggregate co-expression modules built from [[AMP-AD brain RNAseq cohorts]] across seven brain regions: from 2,978 modules, 660 enriched in late-onset cases, and 30 replicated by independent algorithms. Because modules from different regions and cohorts overlap, they are grouped into five consensus clusters by function.

## Connections

- Clusters named in use: B (immune system, inflammation and microglia), C (neuronal system), D (cell cycle and non-mediated RNA decay), E (organelle biogenesis, with lipid processing and metabolism modules). Cluster A is not described in the source below.
- Mouse perturbation signatures were mapped to them by gene overlap and by correlation: the Apoe-driven ivory module matched cluster B, the Clu-driven brown module matched cluster C. Study: [[Late-onset Alzheimer risk gene mouse models mapped to human brain modules]]; method: [[Mouse-human module comparison]]

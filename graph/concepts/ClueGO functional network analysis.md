# ClueGO functional network analysis

ClueGO is a Cytoscape plug-in that groups genes by Gene Ontology and pathway annotation into a non-redundant network with statistics, to suggest shared biological processes.

## Connections

- Run (v2.0.5) on the 23 genes carrying missense variants: amyloid processing ([[PSEN1]], [[SORL1]], [[ABCA7]], [[BACE1]]), tyrosine kinase regulation (OPTN), receptor recycling (SPG11, [[MAPT]]) and synaptic transmission or oxidative stress ([[LRRK2]], [[PRKN]], [[PINK1]]). Study: [[Fifty-gene neurodegeneration panel in eight Thai early-onset Alzheimer patients]]
- Related: [[Gene set enrichment analysis]]
- Run (v2.5.10) on MCODE module genes of six post-mortem brain regions, showing matrix organization up everywhere, hormone terms down outside the cerebellum, and neuroinflammatory versus immune-effector terms in parahippocampal versus superior temporal gyrus. Study: [[Predictive gene expression signatures of Alzheimer disease in six brain regions]]

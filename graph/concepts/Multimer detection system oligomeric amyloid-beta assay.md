# Multimer detection system oligomeric amyloid-beta assay

A blood test for oligomerized [[Amyloid-beta]] that distinguishes multimers from monomers; the result is a score read against a cut-off (0.90 in the Korean assay described below), and a higher score points to amyloid pathology. It is used as a less invasive adjunct to [[Amyloid PET]].

## Connections

- A score of 1.05 against a cut-off of 0.90 supported the diagnosis in a Korean woman with [[PSEN2 p.V226A]]. Study: [[Novel PSEN2 p.V226A in a Korean patient with atypical Alzheimer disease]]

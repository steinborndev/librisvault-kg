# Wnt signaling pathway

The Wnt pathway transmits extracellular Wnt signals; in its canonical branch Wnt inhibits [[GSK3B]], which stabilises [[CTNNB1]] (β-catenin) so that it can drive transcription. It governs neuron survival, differentiation and proliferation.

## Connections

- Proposed as the route by which [[Osthol]] raises [[MIR132]] and protects synapses in an APP-overexpressing cell model, though the reported GSK-3β and β-catenin changes point in a direction the authors do not fully reconcile.

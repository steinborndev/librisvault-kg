# Novel object recognition test

A rodent memory test that exploits the preference for novelty: an animal is allowed to explore two identical objects, and after an interval one is replaced by a new object (novel object recognition) or moved to a new place (novel location recognition). More time or more interactions with the novel item, expressed as a novelty preference or discrimination index, indicate intact memory, and a lower value points to [[Memory impairment]].

# TTN

TTN encodes titin, the giant sarcomeric protein of striated muscle; it is a very long gene in which rare variants are common by chance.

## Connections

- It had the largest number of distinct variants (six) found only in Alzheimer cases in a case-only screen, though it has no known link to Alzheimer disease. Study: [[Case-only rare variant search in Alzheimer Disease Sequencing Project exomes]]
- Disease: [[Alzheimer disease]]

# PRKCA

PRKCA encodes protein kinase C alpha, required for amyloid-beta-induced synaptic loss and implicated in late-onset Alzheimer disease.

## Connections

- Expression was 148% higher in FAK-overexpressing 3xTg-AD hippocampus, consistent with reduced basal dendritic arborization. Study: [[FAK overexpression raises amyloid load and impairs memory in 3xTg-AD mice]]
- Disease: [[Alzheimer disease]]; mouse model: [[3xTg-AD mouse]]

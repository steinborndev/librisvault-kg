# Atabecestat

Atabecestat (JNJ-54861911) is a small-molecule [[BACE1]] inhibitor from J&J/Janssen, stopped in [[Alzheimer disease]] trials over serious toxicity concerns; the source spells it atabacestat.

## Connections

- Named with [[Verubecestat]] as a BACE inhibitor that failed on toxicity, while [[Lanabecestat]] failed for lack of efficacy; some of these drugs lowered plaque burden without slowing cognitive decline. Study: [[Genetics and failed Alzheimer disease therapeutics perspective]]
- Class contrast: [[APP-selective BACE1 inhibitors]]

# CFL1

CFL1 encodes cofilin-1, an actin-severing protein switched off by serine-3 phosphorylation; cofilin-actin rods are a hallmark of Alzheimer disease.

## Connections

- Inactivating S3 phosphorylation rose 113% in FAK-overexpressing 3xTg-AD hippocampus, read as lower cofilin activity. Study: [[FAK overexpression raises amyloid load and impairs memory in 3xTg-AD mice]]
- Disease: [[Alzheimer disease]]; mouse model: [[3xTg-AD mouse]]

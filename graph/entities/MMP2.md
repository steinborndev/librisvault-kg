# MMP2

MMP2 encodes gelatinase A, a secreted zinc protease that degrades extracellular matrix and is considered the more protective gelatinase in Alzheimer disease, partly because it can cleave amyloid-beta.

## Connections

- Aged mouse microglia (16 days in culture) released 2.4-fold more MMP2 activity after amyloid-beta 1-42, while young microglia (2 days) did not change it, which the authors link to a possible stronger ability to cleave the peptide.

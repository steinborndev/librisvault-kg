# TNFRSF1A

TNFRSF1A encodes TNFR1, the main receptor through which [[TNF]] recruits [[RIPK1]] and other adaptors to start NF-κB, apoptotic or necroptotic signalling.

## Connections

- In 10-month-old [[APP-PS1 mouse]] hippocampus, AAV TNFR1 shRNA (at least 70% knockdown) lowered phospho-MLKL by 55.5% and an anti-TNFR1 neutralizing antibody by 45.5%, taken as evidence that neuronal necroptosis depends on TNF-α/TNFR1 signalling. Study: [[TNF-alpha neuronal necroptosis via p62-RIPK1 and UVRAG in Alzheimer models]]
- Ligand: [[TNF]]; process: [[Necroptosis]]
- Disease context: [[Alzheimer disease]]

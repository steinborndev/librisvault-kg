# COS-7

COS-7 is a monkey kidney fibroblast-like cell line that takes up transfected plasmids efficiently and is a common recombinant expression host.

## Connections

- Used to reconstitute the effect of [[P2RX4]] on [[APOE]]: co-transfection lowered ApoE in lysates and supernatants, [[P2RX2]] did not, and the ATP-binding-dead K69A mutant worked like wild-type P2X4. Study: [[P2X4 deletion raises microglial ApoE and rescues memory in APP-PS1 mice]]
- Other cell lines in the vault: [[HEK293]], [[SH-SY5Y]], [[U251]]

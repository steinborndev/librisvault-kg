# CDK1

CDK1 encodes the cyclin-dependent kinase that drives entry into mitosis; inhibitory phosphorylation at Y15 holds it back, and high levels of [[CDKN1A]] restrain it.

## Connections

- Inhibitory Y15 phosphorylation rose 216% in FAK-overexpressing 3xTg-AD hippocampus, read as a cell cycle re-entry signal. Study: [[FAK overexpression raises amyloid load and impairs memory in 3xTg-AD mice]]
- Disease: [[Alzheimer disease]]; mouse model: [[3xTg-AD mouse]]

# HT22

HT22 is an immortalised mouse hippocampal neuronal cell line, used here as a cellular model of amyloid beta toxicity.

## Connections

- Treated with 5 μM amyloid beta 1-42 oligomer ([[APP]]) for 2 hours, the cells showed altered levels of the screened microRNAs, with the largest changes in [[MIR106B]], [[MIR153-1]] and [[MIR155]].
- Used to test the target-specific microRNA fluorescent nanoparticles; see [[Molecular beacon nanoparticle sensor]].
- Study: [[Fluorescent nanoparticle kit for early Alzheimer disease diagnosis]]
